# Harmony Forge — documentation index

One row per document: what it is, whether it is **NORMATIVE** (a rule the code
must obey, or a procedure you must follow) or a **RECORD** (a dated or derived
document — a measurement, a decision history, a generated index — informative,
never a requirement), and when to open it. On conflict, NORMATIVE wins.

**If you read only one thing** — contributor/agent: [SPEC.md](SPEC.md) + the root [AGENTS.md](../AGENTS.md); audio engineer: [THREADING_MODEL.md](THREADING_MODEL.md) + [INVARIANTS.md](INVARIANTS.md); release manager: [DISTRIBUTION.md](DISTRIBUTION.md) + [measurements/ratchet.md](measurements/ratchet.md).

**Generated vs authored:** `docs/MAP.md` is GENERATED by `tools/gen_map.py` — never hand-edit it; regenerate + verify it with `python tools/gen_map.py --check`. Every other document listed here is hand-authored.
