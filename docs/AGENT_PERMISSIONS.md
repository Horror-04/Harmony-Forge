# AGENT_PERMISSIONS: paths agents must not read, write, or depend on

Deny (never open, never edit, never add as a dependency, never assert on
in tests or gates — except the single exempted consumer noted per row):

| denied path | why | only exempted consumer |
|---|---|---|
| `JUCE/` | vendored third-party framework (build-only) | build system includes only |
| `external/` | vendored third-party code (build-only) | build system includes only |
| `*.onnx` | shipped model binaries (sidecar-gated, never parsed by agents) | `src/inference` ORT loader at runtime |
| `training/corpus/sealed_test.jsonl` | SEALED held-out split: no training, eval, smoke, or baseline process may open it | producer `training/ingest/carve_sealed.py` (wrote the split once at creation, never scores) + verifier `training/tests/test_sealed.py` ONLY (manifest cross-checks); the sealed-grep CI gate fails on any other `sealed_test` reference under `training/` |
| `build*/` | generated build trees (configure/build/test outputs) | `ctest` runs and tool `--check` modes that execute built binaries |

Rules:

- The layer gate (`tools/check_layers.py --strict`), the RT gate
  (`tools/rt_scan.py --strict`), the golden-pin lint
  (`tools/lint_golden_pin.py`), and the sealed-grep CI step enforce only:
  banned tokens + layer includes + golden pin + sealed-split isolation.
  **None of them is a STYLE gate.** The style gates are SEPARATE CI steps
  in the `gates` job: the file-size gate (`ci.yml:150`), the Editor
  total-budget gate (`:172`), the UTF-8 gate (`:182`), the max-CCN gate
  (`:197`) and the off-golden literal census (`:208`) — the line numbers
  are this branch's `.github/workflows/ci.yml`. `master`'s CI carries one
  more of them, the repo-hygiene gate (`tools/lint_repo_hygiene.py` — an
  ignored path may not be TRACKED), added by the H1 change.
- `src/core` stays JUCE-free (pure standard C++20); `src/inference` stays
  free of plugin/JUCE-GUI headers. Audio-path (`processBlock` callees) code
  takes no locks, allocates nothing, and performs no I/O or inference.
- New test pins go to golden files (or the `in_test` registry with a stated
  reason). The off-golden census (`tools/lint_off_golden.py`) is a ratchet:
  TOTAL must not grow.
- Navigation without reading deny-paths: `docs/MAP.md` (generated by
  `tools/gen_map.py`; verify with `--check`). Router: `AGENTS.md`.
