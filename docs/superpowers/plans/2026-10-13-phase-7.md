# Harmony Forge Phase 7 Implementation Plan (Visual redesign)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Убрать «дешёвый демо-JUCE» вид: кастомный LookAndFeel, новая палитра с ясной иерархией поверхностей, типографическая шкала, группировка контролов, полировка PianoRoll.

**Architecture:** Три слоя строго по порядку: (1) токены — новые значения + шкала текста/размеров в `UITokens.h`; (2) `HFLookAndFeel` — один раз на редактор, перекрывает кнопки/слайдеры/комбо/скролл/тултипы; (3) по-экранная полировка (PianoRoll, бар-компоненты, сборка редактора). Кажий таск — визуальный слой, ноль логики.

**Tech Stack:** CMake >= 3.22, C++20, JUCE 9.0.3, Catch2 v3, pluginval; ui-ux-pro-max — read-only reference.

**Spec:** `docs/superpowers/specs/2026-10-13-visual-redesign-design.md` (§2 палитра/шкала/компоненты/раскладка/roll; §3 приёмка)

## Global Constraints

- НОЛЬ изменений логики/поведения — только рендеринг, константы, LookAndFeel, layout-геометрия. Reviewer сверяет по диффу.
- NEVER allocate / lock / file I/O / inference in `processBlock`; Phase 7 не касается audio path вообще.
- `src/core` + `src/inference`: ZERO JUCE — не меняются; единственное core-исключение уже сделано в Phase 6 (mapping-функции), не трогать.
- `ctest` both modes green; PPQ/pitch/C3/tonic/drums semantics unchanged. C++20.
- Tripwires: 154/154 Release + 139/139 off; pluginval SUCCESS; seed-7 hash `8CECE0C2…AEE22` identical.
- Zero raw hex outside `UITokens.h` (grep-reviewer verifies; existing exception corners must be migrated).
- NEVER stage/commit unrelated files (explicit `git add` + `git status` every commit); `build*/`, `*.mid`, `external/pluginval/`, `.opencode/` never committed.
- ExplainView known-stale comment (`ExplainView.h` empty-string doc) rides along with the first touch of that file.

## Review Focus

- LookAndFeel применяется и корректно восстанавливается при закрытии редактора — ожидается отсутствие влияния на другие плагины в хосте (global LookAndFeel restore в dtor).
- Контраст новых пар текст/фон — ожидается измеренный ≥4.5:1 тело, ≥3:1 вторичное, а не «на глаз».
- Ноты всех классов на новых цветах палитры — ожидается сохранение различимости и старых cue (hollow/hatch/outline), а не визуальная каша.
- Узкое окно 960×600 — ожидается отсутствие обрезаний/налезаний после смены паддингов.
- Хост-редактор открывается/закрывается многократно — ожидается отсутствие утечек/крешей от LookAndFeel-владельца.
