# Phase 9 Implementation Plan (measure → decode → data → v2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Поднять слышимое качество и новизну системы честным путём: сначала переписанная оценка, потом декодирование без переобучения, потом чистые данные и только затем обучение v2.

**Architecture:** Eval v2 отделяет сигнал обобщения (composed-val, suffix-compliance, per-phase CE) от шума (procedural-val, prefix-carried mean). Декодер выносится из запечённого argmax: логитный ONNX + сэмплер с онлайн-масками (Strict, FSM фаз, anti-memo) в background-потоке. Данные идут через licence-ledger (PD/CC0/CC-BY только, отказ при неизвестном). Обучение v2 — последним, с ранним стопом по CE мелодии на composed-val и решением на заблокированном тесте.

**Tech Stack:** Python 3.14 + torch 2.14.1 (`.venv` CPU / `.venv-cuda` cu130) + ORT 1.22, C++20 + JUCE 9.0.3 (только `src/plugin`), Catch2 v3, pluginval.

**Spec:** `docs/SPEC.md` (§§8–10, 17), `training/MODEL_CARD.md`, GLM second-opinion review (принята с оговорками — см. Task 1–6).

## Global Constraints

- Eval honesty: seed 7 фиксирован; существующие гейты (`compliance ≥ 0.90`, novelty, memo, determinism) и val-разбиение НЕ меняются; новые метрики только аддитивны; старый val остаётся регрессионным набором, финальное решение — на новом заблокированном тесте.
- Licensed-clean ONLY: PD/CC0/CC-BY источники; SA и NC — отказ; CC-BY требует NOTICE с атрибуцией; PD-композиция ≠ PD-кодировка (проверяется кодировка); каждая запись intake — источник + URL + лицензия + хеш, иначе отказ.
- Arch bounds: decoder-only, vocab 256, ctx ≤ 1024, params ≤ 4M (рост до 8M запрещён до ×20–50 данных).
- RT safety: никакого ONNX/сэмплинга/аллокаций/локов в `processBlock`; весь новый C++ инференса — background-потоки через lock-free очереди; `src/core` и `src/inference` — без JUCE.
- Tripwires: `ctest` 154/154 Release + 139/139 off-mode; seed-7 детерминизм; pluginval strictness-5 при пересборке плагина.
- Shutdown-safe: коммит после КАЖДОГО завершённого шага; ledger по задачам; явный `git add` + `git status`; `build*/`, `*.mid`, `external/pluginval/`, `.venv*/`, чекпоинты/логи не коммитятся.
- Greedy-путь и v1-веса продолжают работать на всём протяжении — новый декодер аддитивен, замена только по A/B решению.

## Review Focus

- Транспонированный плагиат проходит токенный memo-фильтр — ожидается интервальный/контурный хеш в новой метрике новизны (тест: Task 1 транспозиционный unit).
- Недекодируемый выход (1/33 + история 15/33) — ожидается 100% decodable через FSM-маску фаз (тест: Task 3/4 fuzz префиксов).
