# Phase 11 Implementation Plan (v2 suffix-targeted retry)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clear the two red DoD bars that shelved v2 (suffix 0.77–0.82 → ≥0.90, new_notes 4.3–5.7 → ≥6.0) with a discriminating cheap experiment first, then full finalists — ship on green, shelve on red, no third retry in this phase.

**Architecture:** The shelf diagnosis says the binding constraint is suffix compliance and Stage 2 never beats Stage 1 (fine-tune overfits the small composed pool). So this phase discriminates cheaply between suffix-targeted levers (suffix-region loss upweighting, composed-only single-stage schedule, stronger melody-pitch penalty) on short runs, commits exactly one recipe to full 5-seed finalists on the locked test, and applies the same ship rule. Keynorm views stay ON in training (T6 precondition met); the product keynorm flag flips ONLY as part of a green ship (v1 was not canonical-trained, so the flag and the weights move together or not at all).

**Tech Stack:** Python 3.14 + torch 2.14.1 (`.venv-cuda` RTX 3060 Ti / `.venv` CPU eval) + ORT 1.22, C++20 Catch2, pluginval.

**Spec:** `docs/SPEC.md` (§§8–10, 17), `training/MODEL_CARD.md` (v2 SHELVED section = baseline to beat), `docs/superpowers/plans/2026-10-14-phase-9.md` Task 6 (honesty gates, DoD, ship rule — all inherited unchanged).
