# Harmony Forge Phase 8 Implementation Plan (model v2: self-distillation + data)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выпустить модель v2 с заметно лучшей новизной при удержанных гейтах: self-distillation на отфильтрованных генерациях + расширенный composed-корпус + архитектура до 4M на GPU.

**Architecture:** Учитель — наша же лучшая модель (лицензионно чисто по построению): генерируем много, фильтруем constraints + novelty + memo-ban, доучиваем студента на отфильтрованном (ReST). Внешний teacher — только stretch при frictionless Apache/MIT PyTorch-варианте с проверенной лицензией, иначе дропается с записью. Каждый таск коммитится сразу (shutdown-safe).

**Tech Stack:** Python 3.14 + PyTorch CPU/CUDA (`.venv` / `.venv-cuda`), ONNX + ORT 1.22, Catch2 v3, pluginval.

**Spec:** `docs/SPEC.md` (§§8–10, 17), `training/MODEL_CARD.md`, `docs/superpowers/plans/2026-10-12-phase-3.md`

## Global Constraints

- Eval honesty rules: fixed seed 7, fixed val split (held-out heads stay held-out), thresholds unchanged (compliance ≥ 0.90 + novelty/memo/determinism PASS), no cherry-picking. New metrics MAY be added, gates NOT lowered.
- Licensed-clean ONLY: self-distillation outputs inherit corpus licences (clean); external teacher/data needs explicit licence proof in MODEL_CARD or it ships nothing.
- Arch bounds: decoder-only, same REMI vocab (256) + ctx ≤1024, params ≤ 4M (CPU inference stays ms-scale).
- C++ production untouched unless a task says so (then: ctest both modes, no JUCE in core/inference).
- Tripwires: 154/154 Release + 139/139 off; seed-7 default hash `8CECE0C2…AEE22` (engine path); pluginval SUCCESS if plugin rebuilt.
- Shutdown-safe: commit after EVERY completed step (code, corpus, weights, eval); never leave >1 uncommitted work unit overnight; ledger updated per task.
- NEVER stage/commit unrelated files (explicit `git add` + `git status`); `build*/`, `*.mid`, `external/pluginval/`, `.venv*/` never committed.

## Review Focus

- Учительская генерация с фильтром — ожидается, что в обучение попадает только прошедшее все фильтры, а не сырой поток.
- Val-ликадж из дистиллята — ожидается, что сгенерированные сиквенсы не содержат val-голов дословно (dedupe против val), а не накачка теста.
- Новый вес vs старый дроп-ин — ожидается загрузка без правок C++ и детерминизм повторных прогонов.
- Новизна выше, compliance удержан — ожидается оба числа лучше-or-равны с раскрытием n.
- Внешний teacher без лицензии — ожидается отказ от него с записью, а не молчаливое использование.
